## 1. Esquema ejecutivo para memorizar

La identificación normalizada de documentos permite reconocer de forma inequívoca publicaciones, ediciones, series, objetos digitales y publicaciones oficiales. En bibliotecas universitarias es fundamental para adquisiciones, catalogación, préstamo interbibliotecario, repositorios, citas, control bibliográfico, preservación y gestión de colecciones.

| Sigla | Nombre | Identifica principalmente | Idea clave |
|---|---|---|---|
| **ISBN** | International Standard Book Number | Libros y publicaciones monográficas | Identifica una edición/formato concreto de una monografía. |
| **ISSN** | International Standard Serial Number | Publicaciones seriadas | Identifica una revista, periódico, boletín, anuario o serie. |
| **DOI** | Digital Object Identifier | Objetos digitales o físicos con referencia persistente | Identificador persistente, resoluble y muy usado en comunicación científica. |
| **D.L.** | Depósito Legal | Publicaciones editadas o producidas para distribución pública | Instrumento jurídico de preservación patrimonial. |
| **NIPO** | Número de Identificación de las Publicaciones Oficiales | Publicaciones oficiales de la Administración General del Estado | Código de gestión, control e información de publicaciones oficiales. |

Frase para examen:

> ISBN e ISSN son identificadores bibliográficos; DOI es un identificador persistente de objetos, especialmente digitales; el Depósito Legal es una obligación jurídica de preservación; y el NIPO identifica publicaciones oficiales de la Administración General del Estado.

## 2. Por qué existen los identificadores normalizados

Las bibliotecas, editoriales, agencias bibliográficas, repositorios, librerías, distribuidores, investigadores y administraciones necesitan identificar documentos sin ambigüedad. Un título puede repetirse, una revista puede cambiar de nombre, una obra puede tener varias ediciones, un mismo artículo puede estar alojado en varias plataformas y una publicación oficial puede existir en varios formatos o lenguas.

Los identificadores normalizados permiten:

- Distinguir documentos semejantes.
- Facilitar la adquisición y el suministro.
- Mejorar la catalogación y el control bibliográfico.
- Favorecer la interoperabilidad entre sistemas.
- Permitir citas estables.
- Localizar recursos en catálogos, bases de datos y repositorios.
- Gestionar derechos, preservación y estadísticas.
- Relacionar obras, autores, versiones, ediciones y soportes.

En una biblioteca universitaria, estos códigos aparecen en registros bibliográficos, catálogos, herramientas de descubrimiento, repositorios institucionales, bases de datos científicas, solicitudes de préstamo interbibliotecario, adquisiciones, bibliografías recomendadas y citas académicas.

## 3. ISBN

### 3.1. Concepto

El **ISBN** —International Standard Book Number— es el número internacional normalizado para libros. Identifica publicaciones monográficas, normalmente libros, y permite distinguir ediciones, formatos y versiones concretas.

No identifica de forma abstracta una obra intelectual en todos sus formatos, sino una manifestación editorial concreta. Por eso, un mismo título puede tener distintos ISBN si se publica en tapa dura, rústica, PDF, EPUB o en una nueva edición.

### 3.2. Qué identifica

El ISBN se usa principalmente para:

- Libros impresos.
- Libros electrónicos.
- Monografías.
- Capítulos o partes comercializables separadamente, si procede.
- Publicaciones multimedia de carácter monográfico.
- Ediciones concretas de una obra.

No debe confundirse con la propiedad intelectual ni con el Depósito Legal. Tener ISBN no significa que la obra esté protegida por derechos de autor —la protección nace por la creación— ni sustituye el cumplimiento del Depósito Legal.

### 3.3. Estructura del ISBN

Actualmente el ISBN es de **13 dígitos**. España usaba tradicionalmente el bloque **978-84** y la Agencia del ISBN ha anunciado un nuevo prefijo para España **979-13**.

Estructura general:

```text
ISBN 978-84-XXXXX-XX-X
     │   │    │     │  └─ dígito de control
     │   │    │     └──── elemento de publicación
     │   │    └────────── editor o sello editorial
     │   └─────────────── grupo de registro
     └────────────────── prefijo EAN
```

### 3.4. Funciones bibliotecarias del ISBN

| Función | Utilidad |
|---|---|
| Adquisiciones | Permite pedir exactamente una edición. |
| Catalogación | Ayuda a diferenciar manifestaciones. |
| Préstamo interbibliotecario | Facilita identificar el documento solicitado. |
| Comercio del libro | Permite distribución, pedidos y trazabilidad. |
| Bibliografías | Facilita la cita y localización de manuales. |
| Detección de duplicados | Ayuda a distinguir ediciones en el catálogo. |

### 3.5. Casos prácticos

**Caso 1.** Un manual recomendado tiene edición impresa y versión electrónica.  
Debe haber normalmente un ISBN diferente para cada formato.

**Caso 2.** Una revista publica un número monográfico con ISBN.  
Puede tener ISSN para la serie y un ISBN para ese volumen concreto.

**Caso 3.** Una tesis doctoral depositada en repositorio no necesita ISBN para existir como documento académico.  
Puede tener otros identificadores, como handle, URI o DOI, según la política del repositorio.

## 4. ISSN

### 4.1. Concepto

El **ISSN** —International Standard Serial Number— es el número internacional normalizado de publicaciones seriadas. Identifica revistas, periódicos, boletines, anuarios, series monográficas y otros recursos continuados.

La Biblioteca Nacional de España explica que el ISSN identifica publicaciones seriadas y que España forma parte de la Red ISSN desde 1978, año en que se creó el Centro Nacional Español del ISSN, actualmente integrado en la Biblioteca Nacional de España.

### 4.2. Qué identifica

El ISSN identifica el título de una publicación seriada, no cada artículo individual. Por ejemplo:

- Revista científica.
- Revista divulgativa.
- Periódico.
- Boletín institucional.
- Anuario.
- Serie monográfica.
- Recurso continuado en línea.

Un artículo de una revista puede tener DOI, mientras que la revista como publicación seriada tiene ISSN.

### 4.3. Estructura del ISSN

El ISSN consta de **ocho cifras**, normalmente presentadas en dos grupos de cuatro separadas por guion:

```text
ISSN 1234-567X
```

La última cifra es un dígito de control y puede ser una **X**.

No incorpora significado sobre país, editor o materia. Su función principal es identificar de manera inequívoca la publicación seriada.

### 4.4. ISSN impreso y electrónico

Una misma revista puede tener:

- ISSN para la versión impresa.
- e-ISSN para la versión electrónica.

Esto permite diferenciar soportes y versiones de una misma publicación seriada.

### 4.5. ISBN e ISSN juntos

ISBN e ISSN no son incompatibles. Una serie monográfica puede tener ISSN para la serie e ISBN para cada volumen concreto.

| Situación | Identificador adecuado |
|---|---|
| Revista científica completa | ISSN |
| Artículo de revista | DOI si se asigna; no ISSN propio |
| Serie monográfica | ISSN para la serie |
| Volumen concreto de una serie | ISBN para el volumen |
| Revista en papel y revista electrónica | ISSN y e-ISSN diferenciados |

## 5. DOI

### 5.1. Concepto

El **DOI** —Digital Object Identifier— es un identificador persistente para objetos. Aunque nació y se generalizó en el entorno digital, puede identificar objetos físicos, digitales o abstractos. Su uso más conocido está en artículos científicos, libros electrónicos, capítulos, datasets, informes, preprints y otros resultados de investigación.

La DOI Foundation lo define como un identificador persistente, una referencia duradera a un objeto o a información sobre un objeto. DataCite también lo presenta como un identificador persistente orientado a identificar y acceder a resultados o recursos de investigación.

### 5.2. Estructura del DOI

Un DOI tiene un prefijo y un sufijo separados por barra:

```text
10.1000/xyz123
│       └─ sufijo asignado por la entidad registrante
└──────── prefijo DOI
```

Suele expresarse como enlace resoluble:

```text
https://doi.org/10.1000/xyz123
```

### 5.3. Función del DOI

El DOI no es simplemente una URL. Una URL puede romperse si cambia la ubicación del recurso. El DOI está pensado para permanecer estable y resolver hacia la ubicación actual del objeto mediante metadatos actualizados.

| Característica | Explicación |
|---|---|
| Persistencia | Debe mantenerse aunque cambie la URL del recurso. |
| Resolución | Permite acceder al recurso o a su página de metadatos. |
| Interoperabilidad | Se integra en bases de datos, citas, repositorios y métricas. |
| Metadatos | Va asociado a información descriptiva del objeto. |
| Citabilidad | Facilita citar artículos, datos, software o informes. |

### 5.4. DOI en comunicación científica

En bibliotecas universitarias y repositorios, el DOI es importante para:

- Artículos científicos.
- Capítulos de libro.
- Libros académicos.
- Conjuntos de datos de investigación.
- Software académico.
- Informes técnicos.
- Preprints.
- Materiales de investigación reutilizables.

En el contexto de ciencia abierta, el DOI se relaciona con la trazabilidad, la citación de datos, la interoperabilidad y los principios FAIR.

### 5.5. DOI, handle y URI

No todos los repositorios usan DOI para todos sus documentos. Algunos usan handles u otros identificadores persistentes. Lo importante es distinguir:

| Identificador | Uso frecuente |
|---|---|
| DOI | Artículos, datasets, capítulos, objetos científicos citables. |
| Handle | Repositorios institucionales y colecciones digitales. |
| URI/URL | Dirección web; puede no ser persistente. |
| ORCID | Identifica autores/investigadores, no documentos. |
| ISBN | Libros/monografías. |
| ISSN | Publicaciones seriadas. |

## 6. Depósito Legal —D.L.—

### 6.1. Concepto

El **Depósito Legal** es una institución jurídica que obliga a depositar ejemplares de publicaciones para garantizar la conservación del patrimonio bibliográfico, sonoro, visual, audiovisual y digital.

La Ley 23/2011, de depósito legal, regula esta obligación y la configura como el mecanismo que permite a la Administración recoger publicaciones reproducidas en cualquier soporte y destinadas a distribución o comunicación pública, gratuita u onerosa, con fines de preservación y acceso cultural, investigador o informativo.

### 6.2. Finalidad

El Depósito Legal no es un identificador comercial como el ISBN. Su finalidad es patrimonial y documental.

| Finalidad | Explicación |
|---|---|
| Preservación | Conservar la producción editorial y documental. |
| Patrimonio | Reunir el patrimonio bibliográfico, sonoro, audiovisual y digital. |
| Acceso | Permitir acceso con fines culturales, de investigación e información. |
| Control bibliográfico | Facilitar la elaboración de bibliografías nacionales y regionales. |
| Memoria documental | Garantizar la conservación para generaciones futuras. |

### 6.3. Publicaciones objeto de Depósito Legal

Son objeto de Depósito Legal, con carácter general, las publicaciones producidas o editadas en España, distribuidas o comunicadas en cualquier soporte o por cualquier medio, tangible o intangible.

Ejemplos:

- Libros y folletos.
- Publicaciones seriadas.
- Mapas y planos.
- Partituras.
- Grabaciones sonoras.
- Producciones audiovisuales.
- Publicaciones electrónicas.
- Recursos en línea, según normativa aplicable.

### 6.4. Código de Depósito Legal

Suele expresarse con siglas de provincia, número y año. Por ejemplo:

```text
D.L. M-12345-2025
```

La forma concreta depende de la oficina de Depósito Legal correspondiente.

### 6.5. Diferencias entre ISBN y Depósito Legal

| Aspecto | ISBN | Depósito Legal |
|---|---|---|
| Naturaleza | Identificador bibliográfico/comercial | Obligación jurídica de preservación |
| Objeto | Monografías y ediciones concretas | Publicaciones destinadas a distribución/comunicación pública |
| Finalidad | Identificación y circulación editorial | Conservación del patrimonio documental |
| Entidad | Agencia del ISBN | Oficinas de Depósito Legal / administraciones competentes |
| Sustituye al otro | No | No |
| Protege derechos de autor | No | No |

## 7. NIPO

### 7.1. Concepto

El **NIPO** es el Número de Identificación de las Publicaciones Oficiales. Identifica publicaciones oficiales de la Administración General del Estado, sus organismos y entidades vinculadas o dependientes.

La Orden PRE/2418/2015 regula la solicitud, asignación y reflejo del NIPO en las publicaciones oficiales, y lo define como un código numérico que las identifica a efectos de gestión, control e información.

### 7.2. Finalidad

| Finalidad | Explicación |
|---|---|
| Gestión editorial pública | Control de publicaciones de la AGE. |
| Información | Facilita la identificación en catálogos y portales oficiales. |
| Control administrativo | Relaciona publicación, organismo editor, soporte, idioma y edición. |
| Transparencia | Ayuda a ordenar la producción editorial pública. |

### 7.3. Estructura

El NIPO suele presentarse en cuatro grupos separados por guiones:

```text
NIPO 123-25-456-7
```

De forma general:

| Grupo | Significado |
|---|---|
| Tres dígitos | Unidad u organismo editor. |
| Dos dígitos | Año de programación editorial. |
| Tres dígitos | Número correlativo de asignación. |
| Un dígito o X | Dígito de control. |

### 7.4. Cuándo aparece

Puede aparecer en:

- Informes ministeriales.
- Guías administrativas.
- Manuales oficiales.
- Folletos de organismos públicos.
- Publicaciones electrónicas de la AGE.
- Publicaciones multilingües oficiales.

### 7.5. Diferencia entre NIPO, ISBN y Depósito Legal

Una publicación oficial puede tener NIPO y, además, ISBN o Depósito Legal si corresponde.

| Código | Pregunta que responde |
|---|---|
| NIPO | ¿Qué publicación oficial de la AGE es y a qué organismo/edición pertenece? |
| ISBN | ¿Qué edición concreta de una monografía es? |
| D.L. | ¿Se ha cumplido la obligación de depósito para preservación patrimonial? |
| ISSN | ¿Qué publicación seriada es? |
| DOI | ¿Cuál es el identificador persistente del objeto citado? |

## 9. Aplicación en bibliotecas universitarias

### 9.1. Catalogación y metadatos

Los identificadores se registran en los metadatos bibliográficos para facilitar la búsqueda, deduplicación y vinculación de recursos. En MARC 21, por ejemplo, suelen aparecer en campos específicos:

| Identificador | Campo MARC frecuente |
|---|---|
| ISBN | 020 |
| ISSN | 022 |
| DOI | 024 u otros campos según práctica catalográfica |
| Depósito Legal | 017 |
| NIPO | Puede recogerse en campos de número normalizado/local, nota o identificadores según política catalográfica |

### 9.2. Adquisiciones

El ISBN permite pedir una edición concreta. El ISSN permite gestionar suscripciones y recursos continuados. El DOI puede ayudar a localizar artículos o datasets. El Depósito Legal y el NIPO ayudan a identificar publicaciones oficiales y patrimoniales.

### 9.3. Recursos electrónicos

En bases de datos académicas y herramientas de descubrimiento, el DOI permite resolver artículos hacia el texto completo, enlazar citas, medir impacto y conectar recursos relacionados.

### 9.4. Repositorios y ciencia abierta

En repositorios institucionales y de datos, los identificadores persistentes facilitan:

- Citación estable.
- Reutilización.
- Interoperabilidad.
- Recolección de metadatos.
- Métricas.
- Relación con autores, proyectos, financiadores y publicaciones.

### 9.5. Préstamo interbibliotecario y acceso al documento

Cuando un usuario solicita un artículo, libro o capítulo, los identificadores ayudan a evitar errores:

- ISBN para libro o capítulo de libro.
- ISSN para revista.
- DOI para artículo o dataset.
- Datos editoriales y año para distinguir ediciones.

## 10. Errores frecuentes de examen

| Error | Corrección |
|---|---|
| “El ISBN protege derechos de autor.” | No. La protección nace por la creación; el ISBN solo identifica. |
| “El ISSN identifica artículos.” | No. Identifica publicaciones seriadas; el artículo puede tener DOI. |
| “El DOI es una URL.” | No exactamente. Es un identificador persistente que resuelve hacia una ubicación o metadatos. |
| “Depósito Legal e ISBN son lo mismo.” | No. Tienen naturaleza y finalidad distintas. |
| “El NIPO se aplica a cualquier publicación española.” | No. Se aplica a publicaciones oficiales de la Administración General del Estado y entidades vinculadas. |
| “Un libro solo puede tener un ISBN.” | Una obra puede tener varios ISBN para distintas ediciones o formatos. |
| “Una revista solo puede tener un ISSN.” | Puede tener ISSN impreso y e-ISSN electrónico. |

## 11. Casos prácticos de examen

### Caso 1

Una profesora solicita que la biblioteca compre la versión electrónica de un manual que ya existe en papel.

**Respuesta:** debe comprobarse el ISBN de la versión electrónica, porque cada formato puede tener un ISBN diferente.

### Caso 2

Un estudiante busca un artículo de revista y aporta solo el ISSN.

**Respuesta:** el ISSN identifica la revista, no el artículo. Habría que pedir título del artículo, autor, año, volumen, número, páginas o DOI.

### Caso 3

Un investigador quiere citar un dataset depositado en un repositorio.

**Respuesta:** si el dataset tiene DOI, debe incluirlo en la cita porque facilita la identificación persistente y la reutilización.

### Caso 4

Una guía publicada por un ministerio incluye NIPO, ISBN y Depósito Legal.

**Respuesta:** no hay contradicción. El NIPO identifica la publicación oficial, el ISBN identifica la edición monográfica y el Depósito Legal responde a la obligación de preservación.

### Caso 5

Una revista cambia de título.

**Respuesta:** puede requerir nuevo ISSN, porque el ISSN se asocia a un título clave de una publicación seriada.

## 15. Glosario

| Término | Definición |
|---|---|
| **Identificador normalizado** | Código regulado por una norma o sistema reconocido que identifica documentos o recursos de forma inequívoca. |
| **ISBN** | Número internacional normalizado para libros y publicaciones monográficas. |
| **ISSN** | Número internacional normalizado para publicaciones seriadas. |
| **DOI** | Identificador persistente de objetos, muy usado en comunicación científica. |
| **Depósito Legal** | Obligación jurídica de depositar publicaciones para preservar el patrimonio documental. |
| **NIPO** | Número de identificación de publicaciones oficiales de la Administración General del Estado. |
| **Publicación seriada** | Recurso publicado en partes sucesivas, generalmente con numeración o periodicidad. |
| **Monografía** | Publicación completa en una o varias partes, no seriada. |
| **e-ISSN** | ISSN asignado a la versión electrónica de una publicación seriada. |
| **Identificador persistente** | Identificador diseñado para permanecer estable y facilitar acceso duradero a un recurso. |
| **Dígito de control** | Dígito calculado para detectar errores en un código. |
| **Objeto digital** | Recurso accesible en formato digital, como artículo, dataset, software o informe. |
